# From a research map to a reading workflow

The selected increment is a personal reading collection, source-linked Markdown
notes and concrete evidence-check tasks. The user selected this package on
2026-10-17 after reviewing alternatives and rough engineering effort. It builds
on the comparison reader without expanding the first screen into a dashboard.

## Reader need

A researcher understands a result, keeps it for later reading and takes its
conditions and exact sources into notes or a journal club. Recorded evidence
limits should become actionable checks rather than disappear during export.
Citation discovery and structured comparisons already exist in ResearchRabbit,
Litmaps, Elicit and ORKG; the product hypothesis is a coherent transition from
understanding a change to reading and checking it, not an exclusive algorithm.
This hypothesis needs real participants; issue #10 remains open.

## Interaction and boundaries

- A quiet **My reading** entry opens an ordered collection. Add a result from
  its inspector, both results from a comparison, or the authored reading route
  from the empty collection. Moving and removing items is reversible.
- The collection is personal intent, not a corpus filter or a claim that an
  item has been read. It has no paper quota. All map results stay available.
- A Markdown research note retains selected results in order, conditions,
  pinned versions, evidence locators, source access, review status and map scope.
- A separate check request carries explicit missing conditions, limited-access
  evidence, unresolved local excerpt matches and recorded map gaps back to the
  host agent. A recorded gap is not automatically an open scientific problem.
  No check is marked scientifically resolved by the browser.
- The browser uses no accounts, telemetry, network research or automatic
  storage. Selection lives in memory and can travel as a view preference in a
  complete exported HTML. Canonical JSON and complete SVG/HTML exports retain
  the full corpus. Reopening and exporting again preserves the collection.
- Empty selections cannot produce a misleading blank research note. Unknown
  conditions and proposed annotations remain explicit. Imported text is data.

## Verification

Exercise production helpers and actual browser controls using the pinned
comparison map, legacy QSP/NMT maps and the 52-work partial surface-code map.
Check ordered add/remove/move, duplicate and invalid IDs, empty selection,
unknown conditions, source/access limits, hostile Markdown and HTML text, and
repeated HTML save/restore without changing canonical data. Download actual
Markdown and HTML in the browser and inspect a narrow viewport. Passing these
software checks does not establish scientific correctness, participant success
or completion of the separate paper-seed research acceptance in issue #12.

No release, version bump, public deployment or background research is included.
