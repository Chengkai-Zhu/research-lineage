表面码如何跨过阈值：论文2408.13687v1的研究谱系

The turning points

A selected account, with the evidence one step away.

011997–2012

先建立可检验的阈值条件

稳定子和拓扑存储把错误定位变为测量与解码问题；理论阈值依具体噪声与经典处理假设，不能直接当作硬件通用百分比。

022014–2021

从条件检测走到重复纠正

重复码先保护单类错误；d=2后选择检测和d=3双类纠正检验不同能力，样本保留率与泄漏处理决定怎样理解寿命收益。

032022–2024

有限尺寸的小收益被推进为跨码距抑错

2022预印本仍明确处于可能转差的交叉区。种子v1在d=3、5、7报告Λ=2.14±0.02，辅以清泄漏与解码改进，支持低于阈值的存储行为。

042024–2026

吞吐、反应时间与错误底限成为独立约束

种子在d=5维持实时吞吐，但63μs端点延迟尚不含逻辑反馈；其10^-10量级底限来自重复码的罕见突发，不能写成二维表面码的已测错误率。

052025–2026

后续走向控制、Clifford逻辑和魔法态资源

动态电路、神经解码和持续调参改善实用性；独立团队已实现d=3无后选择Clifford生成集，另有条件格点手术与约8%保留率的培育实验。更大码距门抑错及实时通用逻辑仍待检验。
